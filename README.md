## Things I build · 正在做的事

### 🧠 [E.R.I.I · 双轨长期记忆引擎](https://github.com/bailong-Hakuryu/E.R.I.I)

为 LLM Agent 构建可形成、巩固与检索的长期记忆，让每一次任务都能站在过去经验之上。

`Python` · `LLM` · `RAG` · `Evaluation`

<br/>

### 🪟 [UpdateLock · Windows 更新守卫](https://github.com/bailong-Hakuryu/UpdateLock)

控制软件的非预期自动更新，把选择权交还给用户；专注原生能力、清晰状态与可逆操作。

`C++` · `Windows` · `ACL` · `Tooling`

<br/>

### 💬 [KouriChat · 角色交互与长期陪伴](https://github.com/bailong-Hakuryu/KouriChat)

探索基于 LLM 的连续角色关系与长期上下文，让角色不只回应当下，也能记得共同经历。

`Python` · `LLM` · `Character AI`
